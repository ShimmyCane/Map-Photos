# Map Photos

**Purpose:** Map photographs onto a PDF site plan with regions, timestamps, and viewing angles.

**Files:**
- `schematic.md` — scope and workflow
- `convo/convo v#.md` — Q&A and decisions
- `04 AI/Map Photos/brief.md` — current state, architecture, next steps
- `04 AI/Map Photos/lessons.md` — patterns and lessons learned

**Data:** All sensitive family data stays offline in `.gitignore`. No real data in git.
